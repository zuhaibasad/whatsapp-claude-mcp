# 2026-10-21/22: from brief to 0.2.0

**Built (all on `main`):**
- **Phase 1:** read-only guard, crypto + keychain, encrypted store + FTS5, daemon helpers, Baileys adapter, CLI.
- **Phase 2:** MCP tools, skills, chat-selection backend.
- **Onboarding v2 for Claude Desktop:** MCP App panel + browser setup page, collector inside the MCP process (no background service), `.mcpb` packaging.
- **After the user's first Desktop test:** contact names + LID→phone, activity/unread for all chats, Channels tab, 7 tools with a single-call `whatsapp_brief`, data dir moved to `%USERPROFILE%\.wa-bridge` with migration.
- **From the OpenClaw review:** untrusted-content notice, quoted replies, context_before, location/vCard (T18); sleep/resume + stall detection, health meta, proxy (T19).

**User feedback that shaped it:**
- Non-technical users, so no terminal.
- Targets are Desktop and Claude Code, not claude.ai web.
- No Task Scheduler.
- Fewer permission prompts.
- Picker-first chat changes.
- Lean token use.

**Key surprises:**
- MSIX redirects new AppData folders, so the data dir moved.
- Desktop kills child processes.
- Packaging pruning once deleted a Baileys file.
