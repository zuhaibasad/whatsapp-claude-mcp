# T12 notes: collector host

## Exports (`src/host/index.ts`)
- `startHost(paths, deps?: Partial<HostDeps>): Promise<HostHandle>` lock election; holder = control server + collector (if linked), follower = retries every 30 s and forwards over HTTP. Idempotent per data dir.
- `stopHost()` stops collector (no logout), server, DBs, removes `service.json`, releases the lock.
- `getSetupOps(paths): HostOps` in-process ops (delegates to HTTP while follower) if `startHost` ran, else `createHostClient(paths)`.
- `createHostClient(paths, {keyring?, timeoutMs?}): HostOps` HTTP client (service.json + keychain control token). Throws `HostUnavailableError` if the holder is unreachable, `HostError(status,msg)` for non-2xx.
- `createHost(paths, deps)` instance without global state (tests), `initDataFiles`, `isInitialised`, `readHostInfo`.
- `HostOps = SetupOps + acceptRisk(nonce?) + mintNonce(): {nonce} + openSetup(): {opened:true}`.
  `acceptRisk` always needs a nonce from `mintNonce()` (in-process too). Embed the nonce only in the panel HTML.
- `HostHandle`: `role()`, `ops`, `collectorState()` (follower: last value seen via `ops.state()`), `ready`, `stop()`.
- `state()` returns `qrSvg`: strip it before anything goes toward the model.

## Routes (127.0.0.1, random port; Host must be `127.0.0.1:<port>`; POST Origin, if present, must be `http://127.0.0.1:<port>`)
- `GET /api/health` (no auth) `{ok,version}`
- `POST /api/{state,accept_risk,start_link,cancel_link,chat_rows,submit_selection,wait_for_sync}` JSON in/out; auth = `Authorization: Bearer <control token>` or session cookie + `X-CSRF` + Origin.
  Bodies: `submit_selection {selectedIds: string[]|null}`, `wait_for_sync {timeoutMs}`.
  `accept_risk`: session, or control token + `X-Accept-Nonce` (single use). Control token alone = 403.
- `POST /api/mint-nonce` and `POST /api/open-setup`: control token only. open-setup opens the browser itself, returns `{opened:true}`.
- `GET /setup?t=<one-time>` consumes token, sets `wab_<port>` HttpOnly SameSite=Strict cookie, 302 to `/setup`. `GET /setup` (cookie) serves `dist/ui/setup.html` (override `WA_BRIDGE_UI_HTML` / `HostDeps.uiHtmlPath`; placeholder if missing) with `<script>window.__WA_HTTP__={"csrf":"..."}</script>` right after `<head>`.
- Errors: non-2xx `{error: "<plain message>"}`.

## Refactors
- `runner.ts`: `startCollector(opts)` (embeddable, no lock/signals) with `state()/onState()`; `runDaemon` wraps it. Collector state: connecting, catching_up (on open), live (caught_up + 5 s quiet, or 60 s after open), reconnecting, logged_out, stopped; written to `meta.collector_state` and `meta.last_live_at`.
- `link.ts`: `runLinkSession(dbs, paths, opts)` (no lock/DB ownership; hooks `onLinked`, `onProgress`, `signal`); `linkAccount` is the lock + DB wrapper.
- `wa-client.ts`: `receivedPendingNotifications === true` -> `caught_up` (once per connection).
- `src/host/init.ts` `initDataFiles` shared with `cli init`.

## Gotchas
- Same-process lock: a second host in one process sees our own pid alive, so it is a follower (used in tests).
- Cancel: during `linking` aborts; during `choose_chats` keeps defaults; later ignored.
- If the collector ends for a non-logout reason it stays `stopped` until the next process start (no auto-restart yet).
- Control token keychain account: `${keychainAccountId(root)}:service-token`.
