# T13 notes: setup UI

Build: `npm run build:ui` -> `dist/ui/setup.html` (single file, ~466 KB: ext-apps `app-with-deps` + zod bundled, minified IIFE, CSS inline). `npm run build` = tsc then build:ui. `npm run typecheck` also runs `tsc -p ui/tsconfig.json` (DOM lib, Bundler resolution, no node types). Root tsconfig does not include `ui/`; tests import only DOM-free `ui/logic.ts`.

## For the server (T12 / T14)
- Template placeholders are already replaced at build time. To embed credentials, inject before `<script>` in the served HTML: `<script>window.__WA_HTTP__={csrf:"..."}</script>` (HTTP page) or `<script>window.__WA_NONCE__="..."</script>` (MCP resource). Inject as a separate script element placed right after `<div id="app">` or in `<head>`; the bundled script runs last and reads them at call time.
- Host selection: `window.__WA_HTTP__` set -> fetch, else MCP App.
- Wire format the UI sends:
  - HTTP: `POST /api/<op>` with headers `X-CSRF`, `Content-Type: application/json`, same-origin cookie, JSON body. Ops: `state`, `accept_risk`, `start_link`, `cancel_link`, `chat_rows`, `submit_selection` (body `{ "selectedIds": string[] | null }`). Errors: non-2xx with `{ "error": "message" }` (shown to the user).
  - MCP: `callServerTool({ name: 'setup_<op>', arguments })`; `setup_accept_risk` gets `{ nonce }` from `window.__WA_NONCE__`; `setup_submit_selection` gets `{ selectedIds }`.
- Response shape the UI accepts: the bare value, OR for `chat_rows` `{ rows: ChatRow[] }`, for `submit_selection` `{ summary: SelectionSummary | null }` (MCP `structuredContent` must be an object, so arrays/null need wrapping). If `structuredContent` is absent it tries to JSON.parse the text content. `isError` results show their text.
- `acceptRisk` must return the new `SetupState`.

## Screens
risk, start (ready_to_link), qr (linking; sanitised SVG via DOMParser, allowlist svg/path/rect), syncing, picker (tabs, search, select all/none on visible rows only, virtualised 60 px rows), done (with summary and "Change chats"), error ("Try again"). Polls `state` every 2 s only in linking/syncing and only while the page is visible. After Save/Skip it calls `notifyDone` (updateModelContext, best-effort) with counts only, never chat names.
