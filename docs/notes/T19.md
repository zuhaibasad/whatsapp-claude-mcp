# T19 notes: connection health + proxy

## Exports (src/daemon/health.ts)
- `proxyInfo(env?) => { enabled, host }` host is `host:port`, never credentials.
- `proxyUrlFromEnv`, `noProxyMatches`, `createProxyAgent` (HttpsProxyAgent for Baileys `agent`/`fetchAgent`).
- `HealthMonitor` (injected `HealthClock {wall, mono}`), `HEALTH_META`, `stallThresholdMs`.

## Meta keys (store.setMeta, throttled to 1 write / 10 s; reconnects written immediately)
- `health_last_frame_at`, `health_last_app_event_at`, `health_connected_at`: unix seconds, '' if none.
- `health_reconnects_24h`: count string. `health_last_reason`: `sleep_resume | app_stall | <close reason>` or ''.

## Wiring
- `WaClientFactoryArgs.onFrame?: () => void`; `createWaClient({ onFrame, env?, agent? })`. Factories must pass `onFrame`
  through (the host's default factory in src/host/host.ts needs this; T20). Without frames, stall detection is off
  (Baileys' own watchdog remains the authority). Frames come from `sock.ws.on('frame')` (listen only).
- `startCollector` options for tests: `healthClock`, `healthTickMs`, `keepAliveIntervalMs`.
- Tick every 15 s. Sleep = wall-minus-monotonic drift > 60 s (or a tick late by > 60 s): immediate close (no logout)
  + connect, state `reconnecting`; skipped while mid-connect. Stall = open, frames seen, and no frame/app event for
  max(4 x keepalive, 5 min): close, reconnect through backoff.
- Proxy log: `proxy: on` (host only) / `proxy: off`.
