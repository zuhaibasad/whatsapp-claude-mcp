# T7 public API (src/daemon: ingest, runner, link, index)

- `runDaemon({ projectRoot, deps? }): Promise<{ stop(): Promise<void>; done: Promise<{reason:string}> }>`
  - deps (all optional): `keyStore(projectRoot)=>MasterKeyStore`, `waClientFactory({auth, logger})=>WaClient`, `logger`, `installSignalHandlers` (default true; SIGINT/SIGTERM call stop()).
  - Throws: lock held (DaemonAlreadyRunningError), "no encryption key found: run wa-bridge init", "not linked: run wa-bridge link". Lock is released on any startup failure.
  - `done` resolves when the daemon has stopped, including fatal stops (logged_out, qr_requested, forbidden/replaced/bad_session). The CLI should await `done` and then exit. Reasons: 'stop' | 'signal' | 'logged_out' | 'qr_requested' | other close reasons.
  - Reconnect: single in-flight attempt, Backoff delays, restart_required reconnects immediately once (resets on open), then backoff.
  - Config reload: config.yaml mtime polled every 30 s, then Ingestor.recomputeIncluded(). Retention at start + hourly; VACUUM when meta.last_vacuum_at is older than 7 days (or missing).
- `linkAccount({ projectRoot, onQr, timeoutMs=180000, deps? }): Promise<{id, pushName}>`; `AlreadyLinkedError`. Takes the daemon lock while linking (so a daemon cannot start meanwhile); a live lock gives "stop the daemon first". Always deletes paths.qrPng in finally. Already linked = hasCreds() and account row exists with status not logged_out/unlinked.
- `Ingestor(store, getConfig, me, logger)`: onChats/onGroups/onContacts/onMessages/onEdit/onDelete/recomputeIncluded(), `counters`.
- `openDaemonDbs(paths, master)` -> { store, storeDb, authDb, auth, close() } (shared helper; T8 may use it for unlink).
- Gotchas: existing chats keep their stored `included`; it changes only through recomputeIncluded() (so a manual setChatIncluded persists until the next config change). Edits are also truncated to maxTextChars. linkAccount treats non-restart closes as failure (no retry).
