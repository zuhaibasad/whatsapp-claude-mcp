# T8 notes: CLI (src/cli)

## Entry
- `src/cli/index.ts` exports `buildProgram(io, deps, setExit)`; runs itself only when it is the process entry (realpath compare). Bin: `dist/cli/index.js`.
- Global `--project <dir>` (default cwd). Exit codes: 0 ok, 1 error, 2 not initialised.
- Commands: init, link, daemon {start [--detach], stop, install, uninstall}, status, chats, new, search, purge, unlink.

## Public API (each command is `(opts, io, deps) => Promise<number>`)
`initCommand, linkCommand, daemonStartCommand, daemonStopCommand, stopRunningDaemon, statusCommand, chatsCommand, newCommand, searchCommand, purgeCommand, unlinkCommand`.
Helpers: `parseDuration`, `parseSince` (duration.ts), `RISK_WARNING`/`ACCEPT_PHRASE` (warning.ts), `CliError(message, code)` and `Io` (io.ts), `openStore/openAuthDb/requireInitialised` (open.ts), `formatTs/relativeAgo/table` (format.ts).

## deps wiring (src/cli/deps.ts)
`CliDeps` holds every side effect (keystore, clock, link/daemon, spawn/kill, QR rendering, WA client factory). `defaultDeps()` is the real one.
`linkAccount` / `runDaemon` come from a lazy literal `import("../daemon/index.js")` (the guard forbids non-literal import()), marked `@ts-ignore` because T7 has not merged; keep it @ts-ignore, not expect-error. The local interface `DaemonModule` mirrors T7 spec §2-3: `runDaemon({projectRoot})`, `linkAccount({projectRoot,onQr,timeoutMs?})`, `AlreadyLinkedError`.

## Behaviour notes
- init skips the prompt when already initialised (key present + store.db exists) and only re-ensures .gitignore.
- `status`: `meta.last_sync_at` accepted in seconds or ms. Link status/daemon warnings as spec.
- `daemon start` foreground: calls runDaemon, waits for SIGINT/SIGTERM, then `stop()` (errors ignored, runDaemon also traps signals itself).
- `unlink`: stops a live daemon via lock pid + SIGTERM (waits up to 10 s), opens auth.db, `createWaClient`, waits for `open` (30 s), calls `unlink()` once. On timeout/failure it wipes locally and prints manual-removal instructions. `--keep-data` keeps store.db, configs and keychain key (link status set to unlinked).
- Avoided the word for the WhatsApp session-end API anywhere in src/cli (guard).

Foreground `daemon start` awaits `done` (exit 0 when reason starts with stop/signal/sigint/sigterm/shutdown/requested, else 1; check T7's actual reason strings). Without `done` it falls back to waitForShutdown + stop(). `unlink` keeps its own DB opening (works; `openDaemonDbs` not used).
