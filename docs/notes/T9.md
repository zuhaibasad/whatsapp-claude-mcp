# T9 notes: MCP server

- `src/mcp/server.ts`: `createServer(deps: McpDeps) -> { server, handlers }`. `handlers` maps tool name to a function for direct tests. Tools: list_chats, get_new_messages, get_messages, search_messages, get_mentions, get_chat_info, get_status, mark_reviewed, save_items, list_items, update_item, export_items.
- `src/mcp/main.ts`: `realDeps(root, keyStore?)`, `runStdio(root, keyStore?)`. Also runnable directly: `node dist/mcp/main.js --project <dir>`. Does NOT import `cli/deps.ts` (that pulls in baileys). Logs go to `.wa-bridge/daemon.log` (event names only).
- `wa-bridge mcp` loads `mcp/main.js` lazily. `wa-bridge items [--status --department --priority --json]`, `items done|dismiss <id>`, `export --format --path --status`.
- `src/export/index.ts`: `isoInZone`, `itemRow`, `toCsv`, `csvCell`, `resolveExportPath`, `writeItemsExport`. Path check also follows symlinks/junctions of the nearest existing ancestor.
- Store is opened per tool call (write connection only for mark_reviewed, save_items, update_item) and closed after.
- Chat args accept id, exact name (case-insensitive), or a unique name fragment; ambiguous gives an error listing candidates. get_messages refuses excluded chats.
- Limits: per-call `limit` clamped to 1000; text clipped by code point to `maxTextChars` with `... [truncated]`; extra total budget of about 80k chars per response (sets `truncated`).
- CSV cells starting with `= + - @` get a leading `'` (Excel formula guard).
- Times accept ISO or `7d`/`12h`/`90m`. Items created_at come from the store's real clock.
- get_status returns a normal result with a warning (not an error) when the store is missing.
