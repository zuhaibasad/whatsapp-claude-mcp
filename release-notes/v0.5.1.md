## New since 0.4.0
- **Buyer leads to Excel.** Ask "find buyers asking for prices and export them to Excel". Claude saves each buy signal as a lead and writes a CSV with name, phone (kept as text in Excel), chat, what they want and their message.
- **Private messages (opt-in, off by default).** With `allow_sending: true` in `config.yaml`, Claude can send one private text to someone who posted in a chat you read, or to an existing 1-to-1 chat (by name or number). You confirm every message, inside Claude or in a pop-up. Max 30 a day. Never to groups.
- **Auto-add new chats** (`auto_add_new_groups`, `auto_add_new_direct_chats`, off by default).
- **Fixes:** the image reader (OCR) no longer crashes the connector; a clear message when old data has no key; a cleanup and folder question on first setup.

## Upgrading
Install the new file the same way. Your link and data stay; the database is backed up before any upgrade.
